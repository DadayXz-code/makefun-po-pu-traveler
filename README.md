One sentence that explains the modern internet to a traveler from 1800, built only from things they already know: a road, a post office, a library. Running `main.py` writes that sentence to `entry.txt`. The program validates the sentence first — exactly one sentence, between 1 and 200 characters — so the output always passes the bounty gate.

## Run it

```sh
python3 main.py
```
